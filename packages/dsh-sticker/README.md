# dsh-lynn-sticker

A DeepSeek Harness bundle that lets an agent send a Lynn-chan sticker inline in the conversation
when the moment fits — without putting the sticker catalog or any image into model context.

- One compact model tool: `send_sticker({ mood, id? })`.
- One short system-prompt hint, about 55 words.
- One-line tool results (`Sent sticker "摸鱼".`), no images or base64 in model context.
- A browser tool view renders the sticker from `tool/result.meta`; animated stickers play a small
  WebM loop and fall back to a WebP still under reduced motion.
- A soft limit of one sticker per assistant turn.

## Install in this repository profile

From the repository root, build the assets once:

```bash
npm run stickers:build
```

Then install the local bundle directory:

```text
plugin_manager install_bundle target=/Users/steven/code/sticker/packages/dsh-sticker
```

Or use **Settings → Plugins → Add local bundle** and choose `packages/dsh-sticker`.

Installing a local directory links the checkout, so the generated `lib/assets` must exist before
install. Rebuild and reinstall after changing the sticker set.

## Use

The agent calls:

```json
{ "mood": "今天终于上线了，开心" }
```

The tool resolves the best sticker server-side and returns one line to the model. The UI shows the
sticker inline. Passing `id` (for example `s-65`) selects an exact sticker from a previous result.

Use it sparingly: it is for warmth and humor, never a substitute for a substantive answer.

## What enters model context

| Item | Approximate cost |
|---|---|
| Tool schema + description | ~150 tokens |
| Prompt hint | ~70 tokens |
| One send result | ~15 tokens |
| Sticker image | 0 tokens (never sent to the model) |
| Catalog | 0 tokens (never injected) |

A second `send_sticker` call in the same turn returns `Sticker skipped: already sent a sticker this
turn.` and renders nothing.

## Assets

`lib/catalog.json`, `lib/assets/thumbs/*.webp` and `lib/assets/anim/*.webm` are generated by
`scripts/build-assets.mjs` from:

- `public/stickers/*.png` — 80 static stickers
- `public/stickers/animated/*.webm` and poster PNGs — 181 animated stickers
- `packages/sticker-catalog/catalog.json` — shared mood metadata

Stills are 256px WebP; animated loops are 240px VP9 WebM at 15 fps, about 7.5 MB in total. Package
assets are served by the Harness client-module route at
`plugins/dsh-lynn-sticker/assets/…`; the host also registers `/lynn-sticker-media/…` with byte-range
support for the WebM loops.

## Packaging

```bash
npm run stickers:build
npm run stickers:pack
```

The tarball is written to `dist/dsh-lynn-sticker-1.0.0.tgz` and verified to contain the manifests,
host/client halves, runtime catalog, icon, locales and every referenced asset.
